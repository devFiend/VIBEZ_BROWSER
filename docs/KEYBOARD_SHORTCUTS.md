# Vibez Browser — Keyboard Shortcuts & Commands

Vibez Browser is designed for keyboard-first power users, researchers, and developers. Every primary browser function can be executed without leaving the keyboard.

---

## 🚀 Signature Features

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| **`Ctrl + K`** | **Open Command Center** | Universal spotlight palette to search open tabs, history, bookmarks, and commands. |
| **`Ctrl + \`** | **Toggle Split View** | Open active tab and secondary tab side-by-side. |
| **`Ctrl + Shift + \`** | **Swap Split Panes** | Swap left and right split view viewports. |
| **`Ctrl + 1` .. `Ctrl + 9`** | **Switch Workspace** | Jump directly to Workspaces 1 through 9. |
| **`Ctrl + Shift + S`** | **Toggle Privacy Shield** | Open the Privacy Shield inspector for the active website. |

---

## 🗂️ Tab & Window Management

| Shortcut | Action |
| :--- | :--- |
| **`Ctrl + T`** | Open new tab |
| **`Ctrl + W`** | Close active tab |
| **`Ctrl + Shift + T`** | Reopen last closed tab |
| **`Ctrl + Tab`** | Switch to next tab |
| **`Ctrl + Shift + Tab`** | Switch to previous tab |
| **`Ctrl + Shift + W`** | Close active window |
| **`Ctrl + N`** | Open new window |
| **`Ctrl + M`** | Toggle audio mute for active tab |

---

## 🧭 Navigation & Page Controls

| Shortcut | Action |
| :--- | :--- |
| **`Ctrl + L`** or **`Alt + D`** | Focus Omnibox / Address Bar |
| **`Ctrl + R`** or **`F5`** | Reload page |
| **`Ctrl + Shift + R`** | Hard reload (bypass cache) |
| **`Alt + Left`** | Back in history |
| **`Alt + Right`** | Forward in history |
| **`Ctrl + D`** | Bookmark current page |
| **`Ctrl + H`** | Open History drawer |
| **`Ctrl + J`** | Open Downloads manager |
| **`Ctrl + +` / `Ctrl + -`** | Zoom in / Zoom out |
| **`Ctrl + 0`** | Reset zoom to 100% |
| **`F11`** | Toggle Fullscreen |
| **`Ctrl + Shift + I`** | Open Chromium Developer Tools |
